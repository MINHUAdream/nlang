# n 0.8-C Binary nIR Artifact Codec Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add a deterministic, integrity-checked `.nir` binary artifact codec for the existing unified nIR phases without changing semantic JSON digests or lowering behavior.

**Architecture:** Encode one canonical nIR JSON payload inside a small framed binary envelope: magic, format version, payload length, payload SHA-256, and payload bytes. Decode validates every envelope field before calling the existing `NIRModule.from_dict`; the decoded module must preserve its canonical digest and phase. File helpers remain thin wrappers over bytes APIs.

**Tech Stack:** Python 3.14 standard library (`struct`, `hashlib`, `pathlib`), existing `NIRModule`, `unittest`, canonical JSON/SHA-256. No third-party codec or compression dependency.

**Spec:** `N_DESIGN.md` M0 codec requirement and the n 0.7 unified phased IR contract.

## Global Constraints

- The codec accepts only unified `n-ir/0.7` modules and preserves semantic/planned/machine phase data.
- Canonical JSON remains the source of the module digest; the envelope digest protects payload bytes only.
- Truncation, unknown format version, invalid length, digest mismatch, and trailing bytes are rejected.
- No new IR phase, lowering rule, runtime effect, or performance claim is introduced.
- Existing JSON round-trip, compiler, native, and receipt replay tests must remain unchanged and green.
